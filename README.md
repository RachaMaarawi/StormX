# StormX - Damascus Flood AI 🌊🤖

A lightweight, interactive web application simulating flood analysis and AI-driven monitoring or prediction models for Damascus. Built as a single-file HTML solution.

## 🚀 Features
- **Interactive Interface:** Clean, responsive UI for visualizing flood monitoring and analytical data.
- **AI-Powered Insights:** Simulation elements representing intelligent weather tracking, water level analysis, or risk assessment.
- **Zero Configuration:** Entirely self-contained within a single HTML file—no complicated server setup or database required.
